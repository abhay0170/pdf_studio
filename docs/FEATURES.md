# Features

This file is the quick map of the product. Update it whenever a major feature is added.

## Current features

- Home: dashboard tab — Scan/Photos quick actions, Import/All Tools, and a recent-documents preview.
- Documents: full library tab, shows an empty state (not yet wired to real device storage).
- Bottom navigation: Home, Documents, Tools (placeholder), Profile (placeholder).

## Planned features, in build order

1. Documents: browse, import, rename, delete, and search PDF files. *(in progress)*
2. Viewer: open a PDF and read it — page navigation, zoom, thumbnails. *(placeholder screen only)*
3. Annotations: add highlights, underlines, drawings, notes, and signatures.
4. Page editor: reorder, rotate, delete, insert, merge, and split pages.
5. Export: save or share the finished PDF.
6. Settings: manage application preferences.

Each item is finished before work starts on the next one.
